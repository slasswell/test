## FAQ Section

**Q: Do I have to start with the Opportunity Assessment, or can I just come to you with a specific use case?**  
A: Either works. If you already have a clear use case and it's well-scoped, we can move directly to implementation scoping. The Assessment is most valuable when you're not sure where to focus or want to ensure you're prioritizing the right opportunities.

**Q: What kinds of AI agents do you build?**  
A: We focus on workflow automation agents — things like intake processing, document summarization, follow-up drafting, report generation, data routing, and multi-step approval workflows. We work primarily with the Claude API (Anthropic), n8n, Make, and Zapier, with custom Python or Node.js for more complex needs.

**Q: How long does implementation take?**  
A: Simpler agents (single function, 1–2 integrations) typically take 3–5 weeks. More complex workflows with multiple integrations and custom logic run 8–16 weeks. We'll give you a scoped timeline before any work begins.

**Q: Will my team be able to maintain the agent after you leave?**  
A: Yes. Every implementation includes a runbook, integration documentation, and a handoff training session. We build for maintainability, not dependency.

**Q: What if the agent doesn't perform as expected after launch?**  
A: Every implementation includes 30 days of post-launch hypercare — bug fixes and minor adjustments included. Beyond that, our retainer plans cover ongoing support and optimization.
