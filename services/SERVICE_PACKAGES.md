## Overview

Services are structured in four tiers that mirror the natural progression of an AI adoption engagement. Most clients enter at Tier 1. The model is designed so each tier earns the next — not through pressure, but through results.

```
Tier 1 — AI Readiness Assessment
  ↓
Tier 2 — Agent Blueprint
  ↓
Tier 3 — Agent Build & Deploy
  ↓
Tier 4 — Retainer / Agent Maintenance
```

Clients may enter at any tier. Fees paid at earlier tiers are credited toward subsequent engagements.

## Tier 1 — AI Readiness Assessment

**Tagline:** Know exactly where AI can help you — before spending a dollar on building it.

**Duration:** 1–2 weeks  
**Price Range:** $2,500–$5,000 (fixed fee, scope-tiered)

### What It Is

A structured intake and discovery engagement that maps a client's core workflows, identifies automation opportunities, and delivers a clear prioritized report. This is the right starting point for any business that knows AI is relevant but isn't sure where to focus.

### What's Included

- Pre-engagement intake call (60 min) and written questionnaire
- 2–3 workflow discovery sessions (90 min each) with key operators
- Process mapping of 3–5 core workflows
- Opportunity scoring across: ROI potential, implementation complexity, data readiness, and strategic fit
- Written **AI Agent Opportunity Report** including:
  - Executive summary with top 3 prioritized recommendations
  - Workflow maps with annotated pain points
  - Opportunity scorecard
  - Rough effort and cost estimates for top recommendations
  - Suggested implementation sequencing
- Report readout and Q&A (60 min)

### Pricing

| Scope | Workflows Covered | Departments | Price |
|-------|------------------|-------------|-------|
| Focused | Up to 3 | 1–2 | $2,500 |
| Standard | Up to 5 | 2–3 | $3,750 |
| Comprehensive | Up to 8 | 3–5 | $5,000 |

**Billing:** 50% at kickoff · 50% at report delivery  
**Credit:** Assessment fee credited toward Tier 2 or Tier 3 engagement within 90 days  
**No implementation required** — the report is yours to use with any partner

## Tier 2 — Agent Blueprint

**Tagline:** A complete plan for what to build, how, and what it will cost — before a single line of code is written.

**Duration:** 2–4 weeks  
**Price Range:** $5,000–$12,000 (fixed fee, scope-tiered)

### What It Is

The Agent Blueprint takes the top 1–2 opportunities from the Readiness Assessment (or a client-supplied use case) and produces a complete implementation plan. This is a standalone strategic deliverable — specific enough that any qualified builder could execute from it.

### What's Included

- Requirements workshop (2–4 hours across 1–2 sessions)
- Workflow redesign: current state → future state with agent
- Tool and platform evaluation and recommendation
- Integration map: what systems the agent touches and how
- Data flow diagram
- Build timeline with milestones and dependencies
- Risk identification and mitigation recommendations
- ROI model: quantified time savings, error reduction, and capacity impact
- Written **Agent Blueprint Document** (15–30 pages)
- Blueprint walkthrough and Q&A session (60–90 min)

### Pricing

| Complexity | Description | Price |
|------------|-------------|-------|
| Standard | 1 use case, clear workflow, 1–3 integrations | $5,000–$7,500 |
| Complex | 2 use cases or 1 complex workflow with 4+ integrations | $8,000–$12,000 |

**Billing:** 50% at kickoff · 50% at delivery  
**Credit:** If preceded by a Tier 1 Assessment, that fee is credited toward this engagement

Full design, build, testing, and deployment of one or more AI agents. Every build is milestone-based and fixed-fee. The client has visibility at every stage. The result is a production-ready agent with complete documentation and 30 days of post-launch support.

- Agent architecture and tool stack finalization
- Build with 2 structured client review rounds
- Integration with existing systems (CRM, email, databases, APIs, cloud storage)

- Deployment to production environment
- Documentation package:

## Engagement Principles

**Fixed-fee by default.** You know what you're paying before we start. No hourly ambiguity, no surprise invoices.

**No lock-in.** Every deliverable — the Opportunity Report, the Blueprint, the agent code and documentation — belongs to you. You can take it anywhere.

**Vendor-agnostic.** We do not accept referral fees or commissions from any tool vendor. Recommendations are based on fit, not financial incentive.

**Honest scoping.** If a project is too large, too complex, or outside our current capabilities, we'll say so and refer you to a better-suited resource rather than overpromise.

**Progress visibility.** Every implementation engagement includes a shared project board with milestones, status, and open decisions — updated weekly.

**You own the outcome.** Our goal is to build something your team understands, can maintain, and is confident using — not to create dependency on us.
